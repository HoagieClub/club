# hoagie.io website

**Hoagie** is the digital experience club at Princeton. Dreamed up for Princeton students, it is a creative space that fosters community-centered design and implementation.

## Running locally

Prerequisites: Node.js and Yarn installed.

Install dependencies and start the development server:

```bash
yarn install
yarn develop
# or
yarn start
```

Build and serve a production build locally:

```bash
yarn build
yarn serve
```

Open the dev server at http://localhost:8000 after `yarn develop`.
